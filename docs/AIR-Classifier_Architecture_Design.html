Resilience

Per LLM rung: timeout · circuit breaker · bulkhead. A failed rung becomes a failed trace step, never an exception.

Summary refresh

Classifies new items via the ladder, merges a deterministic rollup, rewrites the narrative with one guarded gateway call. Stores nothing.

Design principles — why it is built this way

01 · Pay only for the difficulty you have

Most real text ("Great product, thanks!") is trivially classifiable; a cloud LLM costs orders of magnitude more than it needs to. Every request enters at T0 and climbs only when the rung below isn't confident — so the bill follows the hard cases, not the volume.

02 · Degrade, never error

A timeout, breaker trip or gateway outage turns that rung into a failed trace step; the best lower-tier verdict is returned with degraded: true. The only 503 is "no tier produced anything". Readiness stays 200 while T0/T1 can answer.

03 · Every decision is explainable

escalation_trace lists each rung's label, confidence, latency and the reason it climbed. EscalationReason is a closed set — it is also a Prometheus label, so dashboards show why traffic escalates.

04 · Thresholds are config, not code

Confidence floors, margins, latency and cost budgets are all AIR_CLASSIFIER__* settings. Retuning the cost/accuracy trade never needs a logic deploy. Per request: min_tier · max_tier · max_cost_usd (default $0.05).

05 · One model gateway, no vendor code

No provider SDKs or keys in this repo. Vendor choice, failover and spend caps live in air-model-gateway's routing config, per class, with an override for this service. Swapping a model is a gateway change, not a release here.

06 · Privacy before anything persists

PII is redacted before the cache key, before any tier and before any log line. Raw text is never logged in production (startup refuses it). The service is stateless; summaries are stored by the caller.

Vocabulary & compatibility

  • All labels are enums in constants.py: Label, Tone, Topic, Intent, Urgency, RoutingPriority, Actionability, RatingAgreement
  • Adding a member is safe; removing or re-meaning one is breaking and bumps CACHE_SCHEMA_VERSION
  • docs/openapi.json is committed; air-client generates from it; a contract test fails on drift
  • External names kept on purpose: env prefix AIR_CLASSIFIER__, metric prefix air_classifier_

Deployment & operations

Image

  • python:3.12-slim · multi-stage · non-root user air (uid 1001)
  • container port 8080 (local host port 8082)
  • one uvicorn worker per container — scale with replicas
  • built-in HEALTHCHECK on /v1/health
  • 12-factor: every setting is an AIR_CLASSIFIER__… env var

Probes & run modes

  • liveness → /v1/health (process only)
  • readiness → /v1/ready: ok / degraded = 200; 503 only when no tier can answer — never pull a pod for a degraded state
  • make run — native dev loop on :8082
  • make up — container on air-infra's air-net + Redis
  • make up INFRA=none — standalone, in-process cache
  • make doctor — checks every dependency

Production checklist +PROD

  • APP__ENV=production (refuses unauthenticated mode and raw-text logging)
  • real SECURITY__HASH_SALT + key hashes — the dev salt is not auto-rejected
  • MODEL_GATEWAY__TOKEN + base URL; policy & routing entries in the gateway repo
  • CACHE__BACKEND=redis when running > 1 replica
  • Tier-1 ONNX artifact mounted or baked in
  • /metrics restricted to Prometheus · JSON logs · OTel on
